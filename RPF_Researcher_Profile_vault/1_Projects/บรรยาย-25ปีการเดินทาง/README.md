# 25 ปีการเดินทาง (2545–2570)

บรรยาย 20 นาทีให้ทีม NAS ที่เริ่มงานกับกลุ่มแผนงาน และหน้าเว็บคู่กันที่ `/journey`

## ไฟล์

ตัวเลขทั้งหมดอยู่ที่เดียวใน `src/lib/journey.ts` ซึ่งเป็น source of truth ทั้งหน้าเว็บและสไลด์ใช้ชุดนี้ ถ้าตัวเลขเปลี่ยน ให้แก้ที่ไฟล์นี้ก่อน แล้วค่อยแก้ `.tex`

ชุดกล่อง prompt 16 สไลด์อยู่ที่ `2026-10-16_บรรยาย-25ปีการเดินทาง/25ปีการเดินทาง_NAS_promptdeck.pdf` บทพูดรายสไลด์พร้อมเวลาอยู่ที่ `บทพูด-20นาที.md` ในโฟลเดอร์เดียวกัน

## แก่นเรื่อง

แบ่งเป็นหกระยะ บทบาทของ มทร.ล้านนาไต่จากแกนสนับสนุน (2545–2549) มาเป็นแกนร่วม (2550–2565) และเป็นแกนหลักด้านวิศวกรรม (2566 ถึงปัจจุบัน)

ห้าฝ่ายในระบบแต่ละฝ่ายเป็นแกนในมิติของตัวเอง มูลนิธิโครงการหลวงเป็นแกนด้านโจทย์และพื้นที่ สวพส. เป็นแกนทิศวิจัย อว. ร่วมกับการจัดกลุ่ม 2 เป็นแกนนโยบาย งบแผ่นดินหมวดอุดหนุนเป็นแกนความต่อเนื่อง และ มทร.ล้านนาเป็นแกนวิศวกรรมและเทคโนโลยี กรอบนี้เป็นการวิเคราะห์ของกลุ่มแผนงานเอง

งบแผ่นดินปี 2570 มีสามรายการ รวม 8,000,000 บาท คิดเป็น 0.57% ของงบ มทร.ล้านนา 1,398,072,700 บาท ทุกรายการมีชื่อโครงการระบุใน พ.ร.บ. โดยตรง

## ข้อความที่ใช้ได้ และข้อความที่ต้องระวัง

ข้อความที่ใช้บนสไลด์คือ "แกนวิศวกรรมและเทคโนโลยีของเครือข่ายพื้นที่สูง ที่มีรายการงบแผ่นดินระบุชื่อโครงการโดยตรง"

คำว่า "แห่งเดียว" ยังไม่มีเอกสารยืนยัน และแผน สวพส. ระบุภาคีอื่นไว้ด้วย ได้แก่ มช. แม่โจ้ และ มก. จึงพูดได้ด้วยวาจาเท่านั้น และต้องมีข้อมูลรองรับ

การจับคู่กับแผน สวพส. 2571–2575 เป็นข้อเสนอของกลุ่มแผนงาน และแผนต้นทางยังเป็นร่าง
